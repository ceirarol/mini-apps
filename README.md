# MINI APPS

Espacio local para desarrollar aplicaciones pequeñas.

## Apps incluidas

- `patient-companion`: acompañamiento diario para pacientes (plan, progreso, prácticas y reflexiones).
- `therapy-connect`: gestión de citas y chat no urgente con el terapeuta.

Ambas son PWAs estáticas de demostración: los datos de prueba se mantienen en el navegador y no se envía información a ningún servicio.
